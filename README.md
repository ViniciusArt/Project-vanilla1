# To-do List

Esse é meu primeiro projeto onde criei uma lista de afazeres que o usuário pode adicionar quantos itens desejar e marcá-los quando concluídos. Os itens marcados têm um efeito visual "riscado" e ficam levemente transparentes, para criar a sensação de dever cumprido.

## Funcionalidades

- Adicionar quantos itens o usuário desejar
- Marcar tarefas como concluídas (efeito visual: texto riscado + opacidade reduzida)
- Excluir todas as tarefas concluídas, para limpar a tela e permitir melhor visualização do que falta fazer

## Tecnologias usadas

- HTML
- CSS
- JavaScript puro (Vanilla JS)

Como a ideia é ser um projeto vanilla de iniciante, utilizei JavaScript puro junto a HTML e CSS, sem frameworks ou bibliotecas.

## O que aprendi

Antes de iniciar o projeto eu quase não sabia nada sobre CSS. Aprendi a usar os seletores e as prioridades que o CSS dá a depender do que definimos no escopo. Tudo o que está lá eu fui aprendendo ao decorrer dos estudos, conforme as necessidades do projeto foram surgindo.

Aprendi também a usar `data-id` no HTML e `dataset` para ler o `data-id` no JS.
